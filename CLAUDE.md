# Project notes for Claude

- **Work directly on `master`.** Commit and push to `master`; do not create feature branches or open PRs unless asked.
- Web-only changes (`app.html`, `css/`, `js/`) don't trigger an APK build. Changes under `android/` (non-`.md`) do, on push to `master`.
- Run `node test/run-web-tests.js` before pushing.
- Yogas follow Muhūrta Cintāmaṇi (summary of Prakaraṇas 1–2: `docs/muhurta-chintamani-summary.md`). Tables live in `js/data/mc-data.js`, rules in `js/render/mc-yogas.js`: daily windows → Good / Bad Times ring; tithi-vāra-nakṣatra yogas → Secondary yogas view; details → Today Details dialog (`js/today-special.js`). Verse 1.5a follows the commentators (Amṛta, not Mṛtyu). Local practices (e.g. Asal Vākya) are optional, off by default, under Settings > Yogas.
- Calculation methods (`js/engine/sidereal.js`): `drik`, `ss`, `ss-ranganatha` (Makaranda sāriṇī for now, inside `surya-siddhanta.js`), `vakya` (`vakya.js`; its planet tables `js/data/vakya-planets.js` are generated from the md by `tools/build-vakya-planets.py` — fix a reading in the md and rebuild, never edit the js), `vakya-tamil` (Vākyakaraṇa + the Tamil almanacs' mānyādi, fitted to a printed Thanjavur almanac's IST times, which are the reference: Moon at Thanjavur's disc-centre sunrise + 28′ bīja, the same IST instant for every place; `Vakya.tamilLongitude`; test fixture `test/fixtures/vakya-tamil-thanjavur-2026.json`), `ketkar` (`ketaki.js`). Rules, tables, worked examples and implementation status: `docs/graha-sphuta-sources.md`. Each engine is tested against its book's worked example; keep those tests when changing constants.
- Find muhurta (`js/muhurta-finder.js`) uses event rules transcribed from the md's "When is it a good or bad time for N?" section into `js/data/mc-events.js` (one rule per row, with its verse reference). When that md section changes, update `mc-events.js` to match. Date fields use the themed drop-down picker `js/date-picker.js`, never `<input type=date>`.
- Clock screen: the dial's centre holds only the time, the window running now and the time-convention switch; the date, pañcāṅga and outer-ring state are in the Today panel (`js/today-panel.js`, model built in `app.js` `buildPanelModel`). Full screen view puts them back in the centre. No dial label is drawn under 9px on screen (`dial.js` `MIN_LABEL_PX`, `updateScale`): one that cannot reach it is left out and a tap names it.
- Names are stored and matched in IAST. `js/script.js` (`VedicEngine.Script.name`) writes them in the chosen script only where they are drawn (dial, centre, Today panel, ring buttons). Tamil names come from its `TAMIL` table; add a name there rather than changing the data.
